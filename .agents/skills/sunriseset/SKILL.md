# ☀️ SunRiseSet Skill สำหรับ Antigravity (Desktop & CLI)

สกิลนี้ใช้สำหรับให้ AI Agent ใน Antigravity คำนวณเวลาพระอาทิตย์ขึ้น-ตก และสืบค้นที่อยู่ภาษาไทยตามพิกัดหรือชื่อสถานที่ที่ผู้ใช้ระบุ

## คำสั่งเรียกใช้งานของ Agent (Tool Execution)

เมื่อผู้ใช้สอบถามข้อมูล ให้ Agent เรียกใช้คำสั่ง CLI ผ่าน Terminal:

```powershell
# เมื่อผู้ใช้ระบุเป็นพิกัด ละติจูด, ลองจิจูด
python tools/solar_calc.py --lat <LAT> --lon <LON> [--date "YYYY-MM-DD หรือ ปี พ.ศ. เช่น 2569-09-04 / '4 กันยายน 2569'"]

# เมื่อผู้ใช้ระบุเป็นชื่อสถานที่ภาษาไทย (ถนน ตำบล อำเภอ จังหวัด)
python tools/solar_calc.py --location "<ชื่อสถานที่>" [--date "YYYY-MM-DD หรือ ปี พ.ศ. เช่น 2569-09-04 / '4 กันยายน 2569'"]
```

## ผลลัพธ์และรายงานอัตโนมัติ
- คำสั่งด้านบนจะส่งออกผลลัพธ์เป็น **JSON Envelope** และสร้างไฟล์รายงาน Markdown ภาษาไทยลงในไดเรกทอรี `report/` อัตโนมัติ (เข้ารหัส UTF-8 ทั้งชื่อไฟล์และเนื้อหา)
- Agent จะนำข้อมูลไปตอบผู้ใช้เป็นภาษาไทยตามแบบฟอร์มมาตรฐานใน `AGENTS.md`
